英語語根学習システム（Root-Based English Learning System）
#################################################################################################

## 一．概要

本システムは、英単語を単純に暗記するのではなく、
**語根（root）・接頭辞（prefix）・接尾辞（suffix）**
を通じて単語の構造を理解し、体系的に学習することを目的とした学習システムです。

単語の構造を理解することで、意味のつながりを把握し、
より効率的に語彙を習得できるよう設計しています。

---

## 二．開発目的

従来の英単語学習では、単語ごとに個別に暗記する必要があり、
学習効率に課題があると感じていました。

そこで本システムでは、以下の点を重視しています。

- 語根を通じて単語の意味を理解する
- 関連する単語を体系的に学習する
- 英語・日本語・中国語による多言語対応を行う
- 単語同士の構造的なつながりを可視化する

## 四．開発方針

本システムは個人開発プロジェクトであるため、
アジャイル開発（Agile Development）方式を採用しています。

小さな機能単位で設計・開発・テストを繰り返しながら、
段階的にシステムを改善・拡張していきます。

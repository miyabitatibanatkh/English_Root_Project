Root-Based English Learning System
#################################################################################################

## 1. Overview

This system is designed to help learners understand English vocabulary
through **roots**, **prefixes**, and **suffixes**
instead of memorizing words individually.

By understanding the structure of words,
learners can recognize relationships between vocabulary
and improve learning efficiency.

---

## 2. Development Purpose

Traditional vocabulary learning often requires memorizing
each word separately, which can reduce learning efficiency.

This project focuses on:

- Understanding vocabulary through word roots
- Learning related words systematically
- Supporting multilingual learning (English / Japanese / Chinese)
- Visualizing structural relationships between words

英语词根学习系统（Root-Based English Learning System）
#################################################################################################

## 一．概要

本系统并非通过单纯背诵英语单词进行学习，
而是通过 **词根（root）・前缀（prefix）・后缀（suffix）**
来理解单词结构，并进行体系化学习的英语学习系统。

通过理解单词结构，
学习者能够掌握词义之间的联系，
从而更加高效地学习英语词汇。

---

## 二．开发目的

传统的英语学习方式，
往往需要逐个记忆单词，
学习效率存在一定问题。

因此，本系统重点关注以下内容：

- 通过词根理解单词含义
- 系统化学习相关联词汇
- 提供英语・日语・中文多语言支持
- 可视化展示单词之间的结构关系
